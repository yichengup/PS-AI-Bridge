# PS AI Bridge — 使用说明

Photoshop 内的 AI 图像生成面板，连接多种 AI 后端，生成结果可直接插入为 PS 图层。

---

## 安装

1. 将整个 `PS_AI_Bridge` 文件夹复制到 Photoshop 插件目录，例如：
   ```
   C:\Program Files\Adobe\Adobe Photoshop 2026\Plug-ins\External\
   ```
2. 重启 Photoshop，或在 **UXP Developer Tool** 中重新加载插件。
3. 菜单 **窗口 → 扩展功能（插件）→ PS AI Bridge** 打开面板。

**要求：** Adobe Photoshop 23.0.0 及以上版本。

---

## 功能概览

| 标签 | 说明 |
|------|------|
| **全能图片G** | GPT Image 2 文生图 / 图生图 |
| **全能图片Npro** | Nano Pro 文生图 / 图生图 |
| **RH工作流** | RunningHub 云端 ComfyUI 工作流 |
| **本地ComfyUI** | 本地 ComfyUI 直连 |

---

## 快速上手

### 全能图片G / 全能图片Npro

1. 选择 **API 来源**（RunningHub / O官方 / 自定义），填入 **API Key**。
2. 选择 **文生图** 或 **图生图**，输入提示词。
3. 图生图时：点击 **获取选区** 或 **获取全图** 添加参考图（支持多张）。
4. **Aspect Ratio** 选 `auto` 时，图生图会根据输入图片自动匹配最接近的比例。
5. 点击 **Generate**，生成完成后点击 **插入图层** 写入 PS。

可选：勾选 **结果回输**，生成结果会自动作为下一次的输入图，方便连续修图。

### RH工作流

1. 填入 RunningHub **API Key** 和 **工作流 ID**。
2. 加载工作流 JSON（支持 UI / API 格式），指定要暴露的节点编号。
3. 勾选需要暴露的字段，填写参数；LoadImage 节点可从已捕获的图片中选择。
4. 点击生成，完成后插入图层。

### 本地ComfyUI

1. 填入本地 ComfyUI 地址（默认 `http://127.0.0.1:8188`），点击 **测试连接**。
2. 加载 **API 格式** 工作流 JSON，选择要暴露的节点和字段。
3. 可选捕获选区/全图，在 LoadImage 参数中指定对应图片。
4. 点击生成，完成后插入图层。

---

## 常用说明

- **多图输入：** 图生图和工作流均支持多次捕获图片，最多 10 张。
- **精确放置：** 勾选后，插入图层时会自动对齐到原选区位置和尺寸。
- **API Key 存储：** Key 保存在本地 `localStorage`，不会上传。
- **自定义来源：** 选择「自定义」后填写中转地址，协议与对应官方 API 一致。
